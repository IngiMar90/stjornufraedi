# Image sources and attribution

The eight JPEG files are downloaded from NASA Science at the 1024-pixel width supplied by its image service. They are stored locally so exercises work offline and never depend on third-party image requests. The downloaded image pixels are unchanged. CSS changes only the display framing and masks empty corners around the planets. NASA imagery includes composites and enhanced-color products; images should not be described as unprocessed true-color photographs.

The Jupiter image is PIA22946, **Jupiter Marble**, processed by Kevin M. Gill under CC BY, as identified by [NASA's source page](https://science.nasa.gov/photojournal/jupiter-marble/). The in-app atlas and source screen preserve this credit and link. No source pixels were edited; the interface displays a framed version.

The Saturn image is PIA11141, **Saturn … Four Years On**, a Cassini mosaic: [source and credit](https://science.nasa.gov/photojournal/saturn-four-years-on/).

Mercury: [PIA15162](https://science.nasa.gov/photojournal/mercury-globe-0n-180e/). Venus: [Mariner 10, PIA23791](https://science.nasa.gov/image-detail/venus-mariner-10-pia23791-fig2-2/). The other selected files are linked from [NASA's overview of the planets](https://science.nasa.gov/solar-system/planets/).

`starfield.svg` is an original decorative SVG starfield made for this application. It is not an astronomical sky chart. The Sun and the day/night teaching diagram remain original CSS/SVG illustrations. Size-comparison outlines indicate the actual diameter ratios; Saturn's ring system is excluded from diameter comparisons.
